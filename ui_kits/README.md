# UI kits

> **The pages in this folder are layout specimens whose copy is placeholder.** They show how Actorly's pages are put together: spacing, type, colour, cards, motion. They are not the live site, and nothing in them is a statement of fact about the product. True copy comes from the product's own facts (its coverage table, its plans and its data and privacy statements); see `../guidelines/copy-and-claims.md`.

What you may take from a specimen: structure, spacing, type scale, component shapes, motion. What you may not take from a specimen: counts (parts tracked, merchants, reviews), prices and plan contents, dates, release notes, any sentence about data, privacy, security, subprocessors or availability, any "who made it" example presented as real, and any install or store-listing line.

- `website/`: the marketing site's pages, one Design Component each. See `website/README.md`.

A specimen of the embedded Shopify app is not included. The app is built on Shopify's own Polaris web components and looks like Shopify admin; the rules that hold there are in the root `README.md`.
